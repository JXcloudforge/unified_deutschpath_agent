# Deutschpath Unified Agent v0.1.1.dev0

- Version: `0.1.1.dev0`
- Date: 2026-10-13
- Status: unreleased development candidate
- Git commit/tag: none recorded

## Added and improved

- Mixed Sources handling was repaired and a prior P0 run recorded a real
  Tavily response with five results, combined with attachment evidence.
- Chat submission now displays the user message, waits for completion, and
  recovers from uncertain timeouts through session history without replaying
  a non-idempotent request.
- Router rules and Hybrid routing were improved. The reported 300/300 result
  is an engineering development-candidate result, not an independent formal
  98% acceptance result.
- Added local Streamlit API Settings for DeepSeek and Tavily configuration
  status and explicit connection checks.
- Added persistent session rename, search, and recent-activity ordering. The
  archive/restore migration remains blocked pending its schema approval.
- Added the unified `start.bat` launcher and `scripts/run_tests.ps1`, which
  places each run in a dedicated system-temp directory and cleans it by
  default.
- Added version and update information to the Streamlit settings panel.
- Added retrospective M01–M06 technical archive records and a controlled
  manifest-driven evolution panel. Milestone IDs are not Git tags.
- Fixed the launcher readiness probe to validate the Python server process
  below the PowerShell wrapper instead of timing out after startup.
- Archived the four historical source trees with SHA256 verification and
  moved unique local credentials/data/Git metadata to a protected external
  preservation directory before removing eligible work copies.

## Main modules and architecture

- Existing FastAPI, Streamlit, ChatService, CRM/User State, Chroma RAG,
  FileService, Stage 3 Router, Tavily adapter, EvidenceAggregator, and MCP
  servers/host remain the application modules.
- Version metadata continues to come from `pyproject.toml` through
  `app/version.py`; release and milestone records are read from validated,
  repository-controlled manifest paths.
- No additional agent framework or database schema change was introduced by
  this maintenance/release-information work.
