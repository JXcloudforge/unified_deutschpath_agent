# Deutschpath Unified Agent v0.1.0-beta.1

- Version: `0.1.0-beta.1`
- Date: 2026-10-12
- Status: historical local engineering beta acceptance record
- Git commit/tag: none recorded

## Added features

- Unified the Agent/LLM boundary, FastAPI and Streamlit chat, sessions, user
  learning state, file upload, Chroma RAG, three-way Stage 3 routing, Web
  Search adapters, and evidence aggregation in the root project.
- Added separate stdio Database MCP and OCR MCP servers, an MCP Host workflow,
  and confirmation-gated OCR-to-database operations.
- Added local configuration and a single-root launch path.

## Fixes and architecture

- Consolidated the previously separate prototypes into one runnable root
  application while retaining the Stage 3 intent protocol (`rag`,
  `web_search`, `no_tool`) and its separate `mixed_sources` field.
- Kept the MCP planner and host separate from the Stage 3 router.
- Isolated MCP business storage from chat and CRM storage.

## Validation evidence

- Historical full non-TestClient suite: **163 passed, 1 skipped**; compileall
  passed. The skip was Windows symlink creation unavailable in that account.
- Real Uvicorn HTTP, Streamlit health, MCP SDK protocol tests, OCR fixtures,
  and confirmation-gated OCR → database HTTP E2E were recorded as passing in
  `docs/v0.1_beta_acceptance.md`.
- The historical 300-case engineering router candidate scored 268/300
  (89.33%); it was not human-validated and does not prove the formal 98% goal.
