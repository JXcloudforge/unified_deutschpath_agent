## 已查明故障根因

### 问题现象
在开发目录上运行的本地 Chat 未进入预期的 M08 重命名提案流程。

### Root Cause
现有 8765/8501 进程的命令行证据显示，它们来自 `Deutschpath_agent` 开发目录，而不是当前发布副本；该 FastAPI `/health` 显示 `app_environment=development` 但 `m08_local_orchestration=false`，因此请求走普通 Chat 路径。另一个独立的代码缺陷是 parser 未覆盖动词先于“当前会话”的“重命名当前会话为……”形式。根因判断分别由进程路径与 health 字段、以及发布副本上的 parser 复现支持。

### 影响范围
运行旧实例时，M08 入口没有启用；特定重命名语序也未能创建提案。M08 确认执行后 API 返回操作 DTO，但 UI Client 未保留该字段，导致会话标题区域不能立即刷新。

### 修复方法
提供隔离 DemoMode 并在启动时检查 API 健康配置；扩展 parser 的有限语序覆盖；保留 orchestration DTO 并在响应后刷新 UI。业务 Command 和 Query、认证边界及数据库结构均未改变。
