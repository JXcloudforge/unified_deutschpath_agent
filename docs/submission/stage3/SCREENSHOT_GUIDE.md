# Stage 3 六张真实演示截图指南

请从真实本机程序截图；不要编辑截图中的状态、URL、结果或模型回答。截图前确认 Streamlit `127.0.0.1:8501` 和 Deutschpath FastAPI `127.0.0.1:8765` 正常运行，Personal OS `8000` 不需要操作。遮挡浏览器开发者工具、终端环境变量和任何可能包含密钥的设置输入框。

1. **应用与版本**：打开 Streamlit，展开“设置 → 系统信息 → 版本更新”，截取应用名、版本 `0.1.1.dev0` 和更新摘要。
2. **普通聊天与持久化**：新建会话，发送普通德语学习问题，截取用户消息和真实助手回答；随后重载会话历史并截取仍存在的消息。
3. **RAG 附件来源**：上传公开或已获准展示的学习资料，提出附件问题，截取回答中的本地来源引用。避免展示私人附件正文。
4. **真实 Web Search**：输入公开、时效性问题，截取回答、来源标题/URL；确认回答来自本轮在线搜索，而不是 FakeWebSearchProvider。
5. **Mixed Sources**：上传经授权展示的德语学习计划，再输入课程验收问题，截取同时含附件与网页来源的回答。若附件是私人材料，画面需裁切或遮蔽正文；不要截图显示 Tavily 密钥。
6. **服务健康与协议/回归**：用终端运行 `/health` GET 与指定 MCP/pytest 验收命令，截取无密钥的状态码和结果摘要。终端只展示筛选后的输出，不展示 `.env` 内容或进程环境变量。

截图建议命名 `stage3-01-version.png` 至 `stage3-06-regression.png` 并存放在受控课程提交目录。当前仓库只包含截图操作指南；本轮未生成或伪造截图文件。
